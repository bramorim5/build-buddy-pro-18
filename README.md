# Inventory Builder

Quero criar um app de gerenciamento de estoque
Tenho uma empresa e fabricamos alguns produtos
Alguns produtos compartilham partes com outros
Gostaria de poder ter as estruturas do produto detalhadas, com fotos e descrição e também de todos os seus componentes
Gostaria que o app me avisasse quando a quantidade de certo material atingisse o certo limite a definir, para saber quando comprar mais
Gostaria de poder adicionar a compra dos componentes e o app me dissesse quantos equipamentos eu consigo produzir
Quero que seja tudo interligado, passando por suas respectivas submontagens e quando eu montar uma submontagem ou um produto final, que seja descontado dos materiais se for submontagem e das submontagens se forem montagens
Vou incluir uma planilha bem completa para você extrair o máximo de informações possíveis, como peças, submontagens e produtos finais, informações de fornecedores, quantidades atuais e tudo mais
